# Samples

Example config files from a default install, for reference. They are not packs.

- `equipped.json` / `picker.json` — copy next to your packs in `mods/resources/packs/` only if you do not already have these files.
- `models-equipped.json` — example `mods/models/equipped.json`.
- `texture_sync.json` — example `mods/texture_sync.json`.
- `packs-README.txt` / `models-README.txt` — how pack and model folders are laid out.
